# RofiqOlid — Portfolio

Deploy-ready static portfolio built directly from the supplied Canva PDF design and its extracted image assets.

## Deploy

Upload this entire folder to Netlify, Vercel, GitHub Pages, or any static hosting service.

No build step is required.

## Important

All photographic assets in `assets/` are extracted from the supplied portfolio PDF. No stock-photo service or generated personal photography is required by the site.

External media remains external: YouTube and Facebook links open the original destinations supplied in the portfolio.
